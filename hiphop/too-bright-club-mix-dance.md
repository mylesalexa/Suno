# Too Bright (Club Mix) *(teen anthem rebuilt as a progressive-house, TikTok-dance-ready track)*

*One-line concept: the same "Too Bright? Good." song, rebuilt from melodic pop-trap into an uplifting festival progressive-house track: a short vocal hook up front, a rising build, a supersaw drop that carries a call-and-response chant, and a breakdown that holds the song's honest moment before the biggest drop. ## The Dance Moment (suggested routine)

*One distinctive move, repeated, as the research suggests:*

| Lyric | Move |
|---|---|
| "Too bright?" | Shield your eyes with one forearm and lean back |
| "Good." | **Signature move:** drop the arm, throw both arms wide, chest forward |
| "Too loud?" / "Too much?" | Hands over ears / hands on head, each ending in the same wide-open "Good." |
| "Light it up!" | Both hands up, fingers spread, wiggle like sparkling lights |
| "Let 'em talk" | Hand puppet "blah-blah" |
| "I'm turning up the glow" | Turn an imaginary dial, then arms out |

Because the pattern repeats three times ("Too ___? Good."), a new dancer can learn it in one pass, and the breakdown gives a "hands up!" cue before the final drop.

## Clip Structure (estimates)

At 127 BPM one bar is about **1.9 seconds** (4 bars ≈ 7.6 s, 8 bars ≈ 15.1 s).
- **Full club mix:** hook (about 2 bars) → 8-bar verse → 4-bar pre-chorus → **first drop at roughly 26 seconds.** Good for a full-length track, but late for a 15-second clip.
- **Clip edit (included below):** hook → 4-bar pre-chorus → **drop at roughly 11 seconds**, so a 15-second clip catches the drop and the first dance cycle.
- Suno decides the real timing, so treat these as targets, not guarantees. If the drop lands late, use the clip-edit lyrics.
